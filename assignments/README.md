# ASSIGNMENT ARCHIVE / 배운 개념을 적용한 세 번의 SQL 과제

> 2026년 10월 14일에 **SQL 과제 1·2·3 모두 제출**. 아래는 기존 과제 풀이 채팅에서 확인한 실행 결과를 중심으로 복원한 기록이다.

**증거 구분**
- **대화에서 확인:** 당시 사용자가 직접 공유하거나 제출 전 함께 확인한 결과.
- **학습용 재구성:** SQL 개념 노트 및 과제 조건으로 다시 작성한 쿼리. **원래 제출한 쿼리의 복제본이 아니며 현재 DB에서 재실행하지 않았음.**
- **미확인:** 제출 양식의 전체 원문, 일부 Q의 출력 및 원래 코드가 남아 있지 않은 부분. 임의로 채우지 않았다.

**데이터 출처 및 한계**
`kr_claims`는 의료 청구 구조를 본뜬 교육용 가상 명세서 자료이고, `kr_lung_cancer`는 공개 폐암 합성데이터다. 숫자는 실제 병원·환자의 의료 지표가 아니다. 환자 단위 원본 데이터는 이 저장소에 포함하지 않는다.
