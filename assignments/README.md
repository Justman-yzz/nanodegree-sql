# ASSIGNMENT ARCHIVE / 배운 개념을 적용한 세 번의 SQL 과제

> SQL 과제 1·2·3에서 다룬 분석 질문과 기록된 결과를 정리했다. 확인하지 못한 원본 SQL은 임의로 만들지 않았다.

**증거 구분**
- **과제 결과 기록:** 과제 수행 당시 확인해 둔 집계값.
- **복습용 재구성:** 학습 개념과 과제 조건을 기반으로 다시 작성한 예시 SQL. **제출 당시의 코드 원문과 다를 수 있음.**
- **확인 불가:** 일부 문항의 제출 코드·출력값·전체 필터 조건. 확인되지 않은 수치는 표시하지 않았다.

**데이터 출처 및 한계**
`kr_claims`는 의료 청구 구조를 본뜬 교육용 가상 명세서 자료이고, `kr_lung_cancer`는 공개 폐암 합성데이터다. 숫자는 실제 병원·환자의 의료 지표가 아니다. 환자 단위 원본 데이터는 이 저장소에 포함하지 않는다.
