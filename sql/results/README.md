## 해석 제한

- `kr_claims`의 청구/환자 기록은 가상 데이터다.
- 폐암 데이터는 합성데이터이므로 실제 환자의 생존율·치료성과를 의미하지 않는다.

- 환자별 원본 기록과 교육용 데이터셋 전체를 저장소에 공개하지 않는다.
